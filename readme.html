ESP32-FW

Modern firmware designed for the ESP32-S3 platform with a clean graphical interface, Wi-Fi tools, and an optimized ST7789 display driver. This documentation contains everything required to build, flash, and run the firmware successfully.

Installation

Step 1

Download and install the latest version of Arduino IDE. After the installation is complete, launch Arduino IDE once before continuing.

Step 2

Open

File → Preferences

Locate the field named Additional Boards Manager URLs. Paste the following URL. 

https://espressif.github.io/arduino-esp32/package_esp32_index.json

Step 3

Open

Tools → Board → Boards Manager

Search for

esp32

Install

esp32 by Espressif Systems

Step 4

Open

Sketch → Include Library → Manage Libraries

Search for

LovyanGFX

Install the latest available version.

Compatibility

This firmware has been fully tested using ESP32-S3 N16R8 with ESP32S3 Dev Module selected inside Arduino IDE.

Hardware Wiring

This firmware was developed and tested using the ESP32-S3 N16R8 development board together with a 320×240 ST7789 TFT display. The display communicates using the SPI interface and is driven through the LovyanGFX graphics library. If your hardware differs from this configuration, additional changes to the display driver configuration may be required.

Uploading the Firmware

1. Open the Project

Open ESP32-FW.ino using Arduino IDE. All project files will be loaded automatically.

2. Select the Board

Go to

Tools → Board

Select
ESP32S3 Dev Module

3. Select COM Port

Connect your board. Open

Tools → Port

Select the detected serial port.

4. Build & Upload

Click Verify to compile the firmware. If compilation succeeds, click Upload and wait until the board restarts.

Troubleshooting

Compilation Failed

If the firmware does not compile, make sure that:

✔ ESP32 Arduino Core is installed.
✔ LovyanGFX is installed.
✔ ESP32S3 Dev Module is selected.
✔ All project files are inside the same folder.

Upload Failed

If uploading fails:

• Verify the selected COM Port.
• Disconnect and reconnect the USB cable.
• Close the Serial Monitor.
• Press and hold the BOOT button while clicking Upload if your board requires it.

Display Problems

If nothing appears on the display:

• Confirm that your display uses the ST7789 controller.
• Verify the display resolution is 320×240.
• Check your wiring carefully.
• Make sure LovyanGFX is installed correctly.

Board Not Detected

If Arduino IDE cannot detect your board:

• Try another USB cable.
• Try another USB port.
• Reconnect the board.
• Restart Arduino IDE.

Frequently Asked Questions

Which board should I select?

Always select

ESP32S3 Dev Module

inside Arduino IDE.

Which hardware was tested?

This firmware has been fully tested on

ESP32-S3 N16R8

using an ST7789 320×240 SPI display.

Can I modify the project?

Absolutely. You are free to customize, improve, and expand the firmware to fit your own hardware or add new features.

Can I use another display?

Yes. However, you may need to modify the display configuration inside LovyanGFX to match your hardware.
